## Panduan Penggabungan

Untuk menggabungkan seluruh bagian menjadi satu dokumen:

1. **Salin konten** dari setiap file secara berurutan (01 → 11).
2. **Hapus header metadata** (judul file dan separator `---`) pada setiap file kecuali file pertama.
3. **Sesuaikan penomoran halaman** setelah penggabungan.
4. **Periksa referensi silang** antar bab (misalnya "lihat Bab 4A") dan ganti dengan nomor halaman atau sub-bab yang sesuai.

> **Catatan**: Setiap file dirancang agar mandiri secara konteks sehingga dapat dievaluasi secara terpisah sebelum digabungkan.
